# AirdropHub

Peer-to-peer marketplace for crypto, Telegram Stars, Telegram channels, and digital goods.

## Markets

- **Crypto P2P** — USDT, BTC, ETH, TON, SOL vs BDT / USD
- **Telegram Stars** — bulk Stars with gift delivery in-trade
- **Telegram channels** — ownership listings with escrow
- **Digital goods** — Premium, gift cards, bots

## Stack

Next.js 16 · Tailwind CSS 4 · Zustand (local session, offers, trades)

```bash
npm install
npm run dev
```

Production deploy: Vercel.
